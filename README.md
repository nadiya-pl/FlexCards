# FlexCards

**FlexCards** is a simple image gallery made with HTML, CSS, and JavaScript.  
When you click a card, it becomes bigger and shows a title. This effect is smooth and looks modern.

## 🔍 What it does

- Expanding cards with animation
- Works on desktop and mobile
- Clean layout and easy structure
- Custom font and gradient background for text
- Unique images and text — no templates used

## 🛠 Built with

- HTML
- CSS (Flexbox, transitions, media queries)
- Vanilla JavaScript
- Google Fonts: [Urbanist](https://fonts.google.com/specimen/Urbanist)
